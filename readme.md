# 反向扫雷 项目说明

**版本** v1.0.0 ｜ **作者** L1Nzy ｜ **类型** 纯前端单页益智游戏

---

## 一、项目概述

反向扫雷将经典扫雷的推理方向反转：经典扫雷是根据数字推理地雷位置，本作是给定地雷配额，由玩家摆放地雷，使其影响值之和恰好拼出棋盘上的目标数字。

| 项目 | 说明 |
| --- | --- |
| 技术栈 | 原生 HTML / CSS / JavaScript，无框架、无构建工具、无第三方依赖 |
| 渲染方式 | DOM Grid 布局，动态生成单元格 |
| 音效 | Web Audio API 实时合成，不使用音频文件 |
| 数据存储 | `localStorage`，纯本地，无后端 |
| 代码规模 | `index.html` 367 行，`style.css` 2486 行，`game.js` 3230 行，`audio.js` 120 行 |

---

## 二、玩法规则

### 目标

在棋盘上放置规定数量的地雷，使每个格子所受影响值之和等于该格显示的目标数字。

### 操作方式

| 操作 | 说明 |
| --- | --- |
| 点选放置 | 在地雷槽选中地雷类型，再点击棋盘格子 |
| 拖拽放置 | 从地雷槽拖拽至格子；已放置的地雷可在格子间拖动 |
| 右键删除 | 在已放置的地雷上点击右键 |
| 模式切换 | 页面右上角按钮切换点选／拖拽，选择记忆保存 |
| 清空放置 | 一键移除棋盘上全部已放置地雷 |

### 状态反馈

系统实时计算并着色，作为解题的主要辅助：

- **绿色**：当前影响值等于目标数字
- **黄色**：当前影响值低于目标数字
- **红色**：当前影响值高于目标数字

### 胜利条件

地雷全部放置完毕，且棋盘所有格子的当前值等于目标值。

### 边界规则

地雷影响范围超出棋盘的部分不产生效果。该规则是解题关键，例如普通雷（3×3）置于角落时仅 2×2 生效。

## 三、文件结构


## 四、地雷系统

共 22 种地雷，分属 5 个系列。定义集中于 `game.js` 的 `M` 对象，每种地雷包含所属系列、名称、影响函数与范围预览数据。

### 基础系列（6 种，始终开启）

| 名称 | 影响范围 |
| --- | --- |
| 普通雷 | 3×3 范围 +1 |
| 巨型雷 | 5×5 范围 +1 |
| 高爆雷 | 3×3 范围 +2 |
| 竖辣椒 | 竖直方向 5 格 +1 |
| 横辣椒 | 水平方向 5 格 +1 |
| 十字辣椒 | 横竖十字 9 格 +1 |

### 异形系列（4 种）

对角辣椒（3×3 四角及中心）、大对角辣椒（5×5 双对角线）、环形雷（5×5 最外圈）、八向雷（八方向各延伸 2 格及自身）。

### 物理律系列（4 种）

| 名称 | 影响范围 |
| --- | --- |
| 反物质炸弹 | 3×3 范围 −1 |
| 辐射雷 | 中心 +3，内环 +2，外环 +1 |
| 黑洞炸弹 | 中心 −1，外圈 8 格 +1 |
| 大黑洞炸弹 | 中心 −2，内环 −1，外环 +1 |

### 对称系列（4 种）

基于棋盘中心对称点计算，包括镜像双雷、阴阳炸弹、负镜像双雷、对称叁雷。前三者作用于自身与中心对称点，对称叁雷作用于自身、水平对称点与垂直对称点。

### 战术系列（4 种）

该系列效果依赖其他地雷的位置，无法用固定范围表达，由 `applyTacticalEffects()` 在所有地雷效果计算完成后统一处理：

| 名称 | 效果 |
| --- | --- |
| 伤害放大器 | 本格 +1；3×3 内每有一个其他地雷，为该地雷 3×3 额外 +1 |
| 坐标定位器 | 本格无效果；所在行与列的首尾格各 +1 |
| 屏障生成器 | 3×3 范围内所有格子强制归零 |
| 能量虹吸器 | 本格 +1；5×5 内每有一个其他地雷，本格额外 +1 |

处理顺序为：屏障归零 → 放大器计算增幅 → 增幅并入棋盘 → 虹吸器计数 → 屏障再次归零。屏障执行两次是为确保屏障范围内恒为零的语义不被后续效果覆盖。

## 五、难度与解锁

### 预设难度

| 难度 | 棋盘 | 总雷数 | 特殊雷种类 | 特殊雷总数 | 解锁条件 |
| --- | --- | --- | --- | --- | --- |
| 简单 | 8×8 | 4 | 2 | 3 | 开启不少于 3 个系列 |
| 中等 | 10×10 | 8 | 4 | 6 | 开启不少于 3 个系列 |
| 困难 | 12×12 | 12 | 6 | 9 | 开启不少于 3 个系列 |
| 地狱 | 14×14 | 14 | 8 | 12 | 开启全部 5 个系列 |
| 脑王 | 12×12 | 16 | 12 | 14 | 地狱通关不少于 10 次且开启全部系列 |
| 自由 | 10×10 | 6 | 3 | 3 | 无限制，不记录成绩 |

自由模式下可自定义棋盘大小（8-20）、总地雷数（2-24）、特殊雷种类（0-22）、特殊雷总数（0-99）。

### 出题算法

从已开启系列中随机选取特殊雷种类，按配额分配地雷数量，随机撒布至互不重叠的格子，依次累加影响值得出目标数字盘，最后处理战术系列联动效果。由于题目由正向摆雷生成，因此保证有解。

### 系列解锁

基础系列始终开启，其余四个系列需在信息侧边栏完成对应系列的 5 关专项挑战后自动解锁。解锁状态与开关状态分别持久化，因此已解锁的系列可单独关闭，以控制题目中出现的地雷种类。

非自由模式下游戏开始后系列开关即锁定，仅自由模式可重新调整。

### 脑王彩蛋

通关脑王难度后触发专属胜利音效、金色背景与 emoji 彩带，并写入通关标记。此后每次加载页面，标题中的炸弹图标将替换为墨镜图标。

## 六、教学模式

### 引导教学

共 11 关，关卡数据硬编码，每关包含目标棋盘与分步引导文案。知识点依次为：基础操作、边界裁剪、角落放置、大范围地雷、高数值地雷、非方形范围、特殊形状与边界、负值地雷、影响叠加、正负抵消、综合考核。每关分两步引导，操作错误或超时后给出目标位置提示。

### 系列专项挑战

每个系列 5 关，通关后进度自增，满 5 关自动解锁并开启该系列。

## 七、创造模式与题库码

创造模式支持自定义 4-20 行 × 4-20 列的棋盘，自由摆放地雷并实时查看生成的目标数字盘。

### 编码格式

采用二进制编码后经 Base64 转换，并去除尾部填充字符：

| 字节位置 | 内容 |
| --- | --- |
| 0 | 行数 |
| 1 | 列数 |
| 2 起，每 3 字节一组 | 行号、列号、地雷类型索引 |

### 分享与校验

分享文本格式为固定前缀加编码串，粘贴时自动剥离前缀。解码时校验行列数是否在 4~20 之间、棋盘面积是否不超过 400 格、类型索引是否有效，全部校验包裹在异常捕获中，失败时提示且不改动当前局面。

剪贴板写入优先使用异步剪贴板接口，失败时回退至临时文本域方案。

## 八、成就系统

共 45 项成就，其中 14 项为隐藏成就，未解锁时在列表中以占位符显示。分类及数量如下：

| 分类 | 数量 | 说明 |
| --- | --- | --- |
| 新手村 | 3 | 首次通关、正负零同局、完成全部引导教学 |
| 预设难度 | 7 | 各难度累计通关次数与首次通关 |
| 系列道具 | 5 | 基础系列全道具使用、其余四个系列解锁 |
| 速通系列 | 6 | 各难度用时阈值，及五难度最佳成绩总和低于 555 秒 |
| 创造模式 | 5 | 生成关卡、自制关卡类型组合、通关他人关卡 |
| 累计通关 | 5 | 累计 20／50／150／500 局，及夜间通关 10 次 |
| 隐藏 | 14 | 含时段、用时、题目特征等条件 |

判定方式分为四类：一次性触发、计数器达标、用时低于阈值、自定义判定函数。多项成就同时达成时通过队列依次展示，每项展示 3 秒，间隔 0.4 秒。

## 九、音频系统

### 音效引擎

`audio.js` 中的 `AudioFX` 基于 Web Audio API 实时合成。信号链为振荡器经增益节点输出至主增益，音量大于阈值的音效额外接入卷积混响，混响脉冲由指数衰减白噪声生成。首次用户交互时恢复音频上下文，以满足浏览器自动播放策略。悬停音效设有 50 毫秒冷却，避免快速划过时音效叠加。

对外提供放置、移除、确认、胜利、错误、切换等十余种音效接口，以及静音与音量控制。

### 背景音乐

`game.js` 内置 8-bit 风格步进音序器，速度为 110 BPM，采用 16 分音符，四小节共 64 步循环。包含旋律、贝斯、底鼓、军鼓、踩镲五个声部，打击乐由白噪声经滤波合成。调度采用 25 毫秒轮询配合 0.12 秒前瞻窗口。

页面加载时尝试自动播放，若被浏览器拦截则等待首次用户交互后恢复。音量通过侧边栏滑杆调节，范围为 0 至 100%。

## 十、数据存储

全部使用 `localStorage`，清除浏览器数据即重置进度。所有读取均有异常捕获，数据损坏时回退默认值。

| 键名 | 内容 |
| --- | --- |
| `mineRecords` | 各难度最佳通关用时 |
| `mineLastTimes` | 各难度上次通关用时 |
| `mineWins` | 各难度累计通关次数 |
| `seriesState` | 系列开关状态 |
| `seriesUnlocked` | 系列解锁状态 |
| `tutorial_<系列>` | 各系列专项挑战已完成关数 |
| `tutorialStep` | 引导教学进度 |
| `tutorialCompleted` | 引导教学完成标记 |
| `hasVisitedBefore` | 是否首次访问 |
| `welcomeLastShown` | 欢迎弹窗上次展示时间 |
| `brainUnlockedNotified` | 脑王解锁提示是否已展示 |
| `brainCleared` | 是否通关过脑王难度 |
| `achievementState_v1` | 成就系统完整状态 |

## 十一、运行方式

直接打开 `index.html` 即可运行。如需避免个别浏览器对本地文件的限制，可通过本地服务器访问：

```bash
python3 -m http.server 8000
```

需确保 `image/bomb.png` 存在，否则页面图标加载失败，不影响游戏运行。

## 附录：调试入口

主要全局函数可在浏览器控制台直接调用：

```js
newGame()            // 开新局
fullReset()          // 完全重置
clearAll()           // 清空放置
setPre('hard')       // 切换预设难度
startCategoryTutorial('physics')   // 开始指定系列挑战
Achievements.state   // 查看成就系统状态
RetroBGM.toggle()    // 背景音乐开关
AudioFX.setMuted(true)             // 静音控制
```

常用状态变量：`G.tar`（目标数字盘）、`G.placed`（已放置地雷）、`G.pool`（地雷配额）、`wins`（各难度通关次数）、`seriesUnlocked` 与 `seriesState`（系列状态）。
